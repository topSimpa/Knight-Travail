# Knight Travails 
Given two cells, on an 8 X 8 standard chess board, cell A and cell B.
Find the shortest path with valid knight move to go from cell A to cell B.
In CS we refer to this kind of Problem as `Shortest Path Problem`. It is a problem
that is associated or solved using the `map` data structure.
